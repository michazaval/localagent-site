# B · Immersive Signal

Launch from the repository root: `python experiments/site-v3/preview.py --open`, then choose B. Direct path: `/experiments/site-v3/concept-b/`.

**Dramaturgy:** intent becomes a spatial signal; a mode instrument invites experimentation. The second screen establishes the human permission boundary through a reversible, explicitly simulated decision.

**Palette:** deep green `#061410`, field depth `#143a2b`, content `#edf7ed`, secondary `#adc7b9`, mint `#9ce4bb`; mode accents also use pale blue, teal and gold. System sans with a Georgia italic display line: a voice contrast specific to this direction, not a dependency on remote fonts.

**Motion and input:** a deterministic Fibonacci point volume rotates and follows pointer/touch. IDLE breathes; THINK folds the depth field; LISTEN pulses its radius; ACT directs its flow. State blends use exponential smoothing. Mode buttons, an intensity range, pause and permission toggle have native keyboard alternatives. No microphone, filesystem or AI API is touched.

**Technology:** native WebGL points, original vertex/fragment shaders, 1,800 points on initial mobile viewport or 3,400 desktop. SVG orbital study is the static fallback, and captions still describe the selected conceptual mode. No third-party visual assets/libraries; see [provenance](../LICENSES.md).

**Trade-off:** most expressive immediate motion and lowest geometry cost, but legibility of particles, overdraw and the familiar AI-sphere motif require further identity work if chosen. Mobile controls sit after the field, below the first viewport. Evidence and limits: [comparison](../README.md).
