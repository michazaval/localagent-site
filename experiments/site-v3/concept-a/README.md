# A · Sculptural Clarity

Launch from the repository root: `python experiments/site-v3/preview.py --open`, then choose A. Direct path: `/experiments/site-v3/concept-a/`.

**Dramaturgy:** understand the product first, inspect one tactile object, then explore models/context/control. Bright spacious hero → deep-green principles screen. Minimal direction; no decorative glass panels.

**Palette:** ivory surface `#eeeee6`, forest content `#153b2e`, muted green `#516258`, lime accent `#c8f28e`, deep section `#16372b`. Segoe UI/system sans with Cyrillic; a large, lightly weighted sentence-case heading.

**Motion and input:** a slowly turning interlocked form with studio-strip reflections; pointer/touch adjusts the viewing angle. Named range supports keyboard inspection. Principle buttons reveal explanatory copy and alter the form's angle. No actual model or memory store.

**Technology:** original WebGL SDF surface (twisted torus + inner ring). SVG silhouette without WebGL/JS or in Lite mode. Pause/reduced motion retain static content and explicit controls. No third-party visual assets/libraries; see [provenance](../LICENSES.md).

**Trade-off:** strongest immediate clarity and smallest interaction surface. Light surroundings and restraint may deliver less futuristic drama; raymarch edge quality needs refinement if selected. Detailed screenshots, motion, QA and limitations: [comparison](../README.md).
