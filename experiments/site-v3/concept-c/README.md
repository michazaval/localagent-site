# C · Cinematic Journey

30 October update: materials, accent and surroundings now use the green immersive family, replacing the copper direction. [Fresh green capture](../concept-b-immersive/evidence/c-green.png). Earlier palette/captures below describe the original exploration.

Launch from the repository root: `python experiments/site-v3/preview.py --open`, then choose C. Direct path: `/experiments/site-v3/concept-c/`.

**Dramaturgy:** potential → illustrative reasoning → local boundary → conservative development roadmap. A single object evolves with those four ideas. The visitor controls the pace; no scroll hijacking or locked transitions.

**Palette:** graphite `#141b19`, warm white `#e8e5d7`, muted sage `#b9bfb1`, olive `#d6d5a0`, copper-tinted object lighting. Georgia serif headlines paired with system sans interface/body text. Real sequential chapter numbers encode narrative order.

**Motion and input:** native scroll interpolates a sphere into an octahedral form, a rounded cube and an open boundary. Pointer inspection and a desktop keyboard range change its viewing angle. Numbered native anchors offer direct chapter access by touch or keyboard. Reduced motion stops object scrubbing and sticky placement while keeping every chapter legible. Mobile uses a compact pinned form and chapter links.

**Technology:** original WebGL SDF scene with scroll uniforms. Original SVG boundary form in Lite/no-WebGL/no-JS. No third-party assets/libraries; see [provenance](../LICENSES.md).

**Trade-off:** strongest story potential, highest implementation and maintenance risk. Requires visitors to invest scrolling time. Mobile loses some cinematic scale; production choreography, device testing and edge quality remain future work only after owner approval. Evidence and limitations: [comparison](../README.md).
