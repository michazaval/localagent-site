# Source and asset provenance

- The HTML, CSS, JavaScript, GLSL signed-distance scenes, Fibonacci particle geometry and SVG fallback illustrations in this exploration were authored for LocalAgent. No third-party source, models, textures, HDR environments or stock imagery were incorporated.
- No runtime packages or remote scripts are required. Native WebGL, browser APIs and Python's standard-library HTTP server are used. No GSAP, Three.js, React, WebGPU framework or production dependency was installed.
- Segoe UI, Arial, Georgia and Times New Roman are requested as locally installed system fonts, with generic fallbacks. Font files are not redistributed.
- Evidence PNGs and MP4s are captures of these prototypes and of the repository's current develop website. Videos contain no third-party audio. Playwright, Chrome, Lighthouse and FFmpeg are local verification tools, not shipped site dependencies.
- The small Playwright FFmpeg/Winldd capture helpers were downloaded to the existing external browser-tool cache, not to this repository or the product's runtime.
