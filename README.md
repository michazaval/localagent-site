# UniTeam

Official landing page for UniTeam, an independent personal software project.

## Website

This is a standalone HTML/CSS site. Upload `index.html` to the root of this repository.

To publish it for free, open **Settings → Pages**, set **Source** to **Deploy from a branch**, and select `main` / `(root)`.

Public site URL: https://michazaval.github.io/uniteam-site/

UniTeam is a personal project, not a registered company.
